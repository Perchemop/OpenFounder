## Licence classes

All production dependencies fall into permissive licence classes:

- **Permissive MIT**: react, react-dom, vite, @vitejs/plugin-react, tailwindcss, zod, express, dotenv (BSD-2), lucide-react (ISC is permissive), motion, esbuild, vitest, tsx, autoprefixer, @types/*
- **Apache-2.0**: dexie, @google/genai, typescript

No copyleft, source-available, or network-copyleft dependencies are present. A CI licence gate will reject a PR that introduces non-permissive classes. Dependency licences are also recorded in the SBOM generated by CI.

## Non-code assets

- No images, fonts, audio, or video files are bundled. The mark `assets/logo.svg` is original to this repository (project licence).
- Icons are rendered from `lucide-react` at runtime.
- Demo data is original and synthetic; every synthetic row carries `isSynthetic: true`.

## AI model and API terms

- The application allows the user to optionally connect external AI providers (Gemini, OpenAI-compatible, Ollama). Keys are stored in the user's browser profile and never transmitted anywhere but the provider chosen by the user.
- Agent development for this repository used OpenCode free models and NVIDIA free models; no model output whose terms prohibit redistribution is committed to the repository. Model names are documented in `docs/current-model-map.md`.
