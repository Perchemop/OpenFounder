# Contributors

This project credits everyone who contributes, not just people who commit code. If you
contributed and are missing here, open an issue or a pull request that adds you — the omission is
a bug.

## Maintainer

- [@Perchemop](https://github.com/Perchemop) — project owner, release approvals, direction.

## Development

- **OpenFounder Dev** (`dev@example.com`) — the agent development team's git identity. Every
  commit, pull request, merge, and tag an agent makes on the app's behalf is authored as this
  identity; the planning, implementation, and CI slices it produced are recorded in
  `PROGRESS.md`. This is the project's automation identity, not a human person.

## How contributions are recognised

- Merged code, tests, documentation, and design are credited here.
- Triage, issue reproduction, translations, and accessibility reviews count and are credited on
  request.
- Security reporters are credited in the release notes unless they prefer to stay anonymous.

## Template for adding yourself

```markdown
- [@your-handle](https://github.com/your-handle) — what you contributed.
```
