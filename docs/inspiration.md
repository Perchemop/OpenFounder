# Inspiration and Clean-Room Boundary

OpenFounder is an original implementation. No proprietary source code, assets, icons, layouts,
strings, or internal algorithms from any commercial product have been read, copied, or fed to an
agent.

## Public frameworks and documented methods

| Source | What is borrowed | Nature |
| --- | --- | --- |
| Lean Canvas (Ash Maurya, public framework) | Section names for the business-model canvas | Publicly documented method |
| Customer Development / "The Mom Test" (public talks and book concepts) | Interview questions must be about past behaviour, not hypotheticals | Publicly documented method |
| Build-Measure-Learn / lean startup vocabulary | Hypothesis → experiment → evidence loop | Publicly documented method |
| MoSCoW prioritisation | Must/Should/Could/Won't labels | Publicly documented method |
| Risk matrix (probability × impact) | 3×3 scoring convention | Standard practice |

## Products used as black-box feature inspiration only

These were considered by category ("what job does a founder need done"), never by inspecting
their code or copying their UI:

- Notion / Airtable — generic information-density and workspace navigation expectations
- Google Sheets templates for validation — expected fields in a founder tracker
- Generic AI chat assistants — expectation of a side panel with project context

Observed behaviour only: a founder wants one place for claims, sources, experiments, and
decisions. The information architecture, command set, visual language, and copy in this
repository are original.

## Explicit exclusions

- No competitor code, minified bundles, database dumps, API internals, or private documentation.
- No copied icon sets, illustrations, or brand palettes.
- No marketing copy reproduced from another product.
